## Archives

`research/` and `planning/` are dated working documents kept as-is, including
[planning/PRODUCT_ARCHITECTURE_AUDIT.md](planning/PRODUCT_ARCHITECTURE_AUDIT.md),
the architecture audit that drove the current rework and is unkind to the code
it found.

They call the project **`component-intent-audit`**, its name before it was
`reuse-me`. They have deliberately not been rewritten: they are a record of
what was decided and when, and editing them to match the present would make
them worse evidence, not better.
